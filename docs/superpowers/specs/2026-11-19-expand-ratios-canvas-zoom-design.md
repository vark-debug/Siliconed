# 扩图比例重算 + 画布缩放 — 设计

日期：2026-11-19　状态：已批准

## 1. 扩图比例按钮：以原图为基准的绝对重算（ExpandEditor.snap）

每次点击 chip 丢弃当前 pads，从原图 (w×h) 重算：

- 图片比目标比例窄 → 左右各扩 `((W/H × h − w) / 2 / w) × 100%`，上下归零；宽则对称扩上下
- 图片恰好符合比例 → 四边各 30%（比例保持）
- 超过 pads 上限（200%）钳制，画布比例以读数为准
- 拖手柄仍进「Free」；chip 高亮跟随点击

修复两个叠加缺陷：累积计算（连续切换逼近 5120 极限）与 per-side/total 混淆（单点 4:3 得 5:3）。

## 2. 画布缩放按钮：工具栏 − / % / ＋

- toolRail 底部（分隔线下）加缩放组：`−`、`%`、`＋`；步进 ×1.5/÷1.5，范围 1–8；% 显示当前缩放、点击 = 复原适配
- 两套状态：图片画布 → `app.zoom`；扩图编辑器 → 新增 `app.expandZoom`（离开扩图工具复位 1）
- 显示条件：画布上有图（原图或历史图片）；蒙版绘制、探索网格时隐藏

## 3. 滚轮：解锁盲区（SceneView 监视器）

- 原图未渲染前：鼠标滚轮可缩放（当前只对历史图片生效）
- 扩图编辑器内：滚轮以指针为锚缩放整个编辑器内容——缩放折进 `fitted(in:)` 布局尺寸（不用 scaleEffect，手柄拖拽换算自动正确）；`.clipped()` 防溢出
- zoom > 1 时触控板/横向滚轮平移编辑器内容

## 4. 收尾

菜单 ⌘+/⌘−/⌘0 可用条件扩展到原图状态；新文案走 Localizable.xcstrings；dev 包构建后逐项实测。

## 决策记录

- 等比例时四边均匀扩 30%（用户选定，备选「仅提示」被否）
- 扩图编辑器内也加缩放（用户选定，扩大了原推荐范围）
- 缩放控件只在工具栏一处（编辑器底部条备选被否）；扩图用独立 expandZoom（共用 app.zoom 备选被否）
